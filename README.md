# ♻️ EcoScan IA — Sistema de Visión Artificial para CARAMA

**EcoScan IA** es la interfaz y módulo de visión por computador diseñado para **CARAMA** (*Clasificación Automatizada de Residuos para el Aprovechamiento de Materiales Aprovechables*), un prototipo de máquina inteligente concebido para optimizar la gestión de residuos y reducir el volumen de desechos enviados a los Relleno sanitarios.

---

## 🤖 ¿Qué es CARAMA y para qué sirve?

**CARAMA** es un sistema automatizado que combina inteligencia artificial, sensores ópticos y procesamiento de imágenes en tiempo real para separar materiales en origen antes de que se conviertan en basura no recuperable.

* **Orgánicos:** Destinados a la producción de abono mediante el método **Bokashi**.
* **Plásticos:** Recuperados para la fabricación de bloques de construcción y reciclaje industrial.
* **No Aprovechables:** Clasificados para su disposición final adecuada.

---

## 🛠️ Stack Tecnológico

* **Frontend & Interfaz de Control:** HTML5, CSS3, JavaScript (Vanilla).
* **Visión Artificial / IA:** TensorFlow.js, modelo entrenado en Teachable Machine.
* **Despliegue:** GitHub Pages.
